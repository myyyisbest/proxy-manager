# 应用代理管理器 1.4.4 验证记录

本次交付文件为同目录的便携 ZIP 和安装 EXE（1.4.4）。1.4.1–1.4.4 在 1.4.0 的修复基础上追加以下内容；真实 TUN 网络验收在本机（Windows 11 x64，无可用 IPv6 出口）以 IPv4 范围完成，1.4.4 已实机安装并运行。

## 版本变更

**1.4.4**
- 托盘图标恢复常显：Win11 默认把新图标收进折叠区；现由程序在 explorer 建立托盘条目后写 `IsPromoted=1`（枚举 `HKCU\Control Panel\NotifyIconSettings` 匹配本程序路径，支持 KNOWNFOLDERID 相对路径形态；只改 explorer 建好的条目，不自行建键）。实机已验证正式安装条目 `IsPromoted=1`。

**1.4.3**
- 关闭窗口默认驻留托盘：v2 配置一次性迁移为开启（此前沿袭旧版"关闭即退出"），首次驻留弹气泡提示退出入口；设置页仍可关闭。
- 启动时按配置重新登记自启动：1.4.x 改用当前用户计划任务，旧版 HKCU Run 键随升级消失；若配置要求自启动而任务缺失则自动补建（实机已验证任务 `ProxyManager-<SID>` 就绪）。

**1.4.2**
- 进程识别冷窗口（核心修复）：sing-box 启动后约十秒内进程搜索器未就绪，连接查不到进程归属，选中应用规则不命中、流量静默直连；每次重启内核（含配置热切换）重现。启动就绪除 API 探测外，还会主动产生探测连接并轮询 clash-api `/connections`，确认任一连接已带非空 `processPath` 才宣告运行（上限 20 秒，超时降级放行并留日志）。
- 顺带核实：sing-box 1.14.3 Windows 下报出的进程路径即普通盘符路径，`process_path` 精确匹配可用。

**1.4.1**
- 切换竞态：切换进行中（Starting/Stopping）到达的配置保存会被静默丢弃；现置位补跑，切换完成后自动应用最新配置（仅干净完成后补跑，失败路径不自动重试）。新增确定性回归用例。
- 发布锁文件拆分：csproj 内按 RID 拆分 NuGet 锁文件的写法在 dotnet CLI 下不生效，"先普通构建、后发布"会挂 NU1004；现由 release.ps1 显式传 `-p:NuGetLockFilePath=packages.win-x64.lock.json`。测试项目加入解决方案。

## 验证结果（截至 1.4.4）

- Release 编译 0 警告 0 错误；隔离回归 11 项全过（含切换窗口补跑、v2→v3 迁移两条新用例）。
- 真实 TUN 验收（`--network-check-ipv4`）通过：选中进程经 TUN 送达本地认证上游、未选中进程 IPv4 直连不受影响、增强 DNS（fake-IP）把原始域名交给上游、停止后 TUN 网卡移除、系统 DNS 不变、直连恢复。证据：validation/network-evidence.json（`ipv6DirectWorks: null` = 本机无 IPv6 出口，按脚本标注未测试）。
- 包验收：便携 ZIP 与安装 EXE 逐文件哈希、无运行数据夹带、实际启动/退出、以独立验证标识安装/卸载且不影响正式安装注册。证据：package-verification.json、SHA256SUMS.txt。
- 实机部署：安装版位于 `C:\Program Files\ProxyManager`（AppId 固定，原地升级；1.3.0 旧目录已随升级自动清理），当前运行版本 1.4.4.0，分流运行中，托盘图标常显，自启动计划任务就绪。

## 边界说明

- 真实验收的上游是验收程序自带的本地认证 SOCKS 服务，节点可达性取决于上游本身（本机 Clash 共存链路逐环节已验）。
- 安装包未做数字签名；程序含 .NET 运行时，启动需管理员权限。操作方法见包内使用说明.md。
